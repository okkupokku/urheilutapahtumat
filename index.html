Datalähteiden tila ▸

Ensimmäinen live-versio. Jalkapallon ottelut haetaan taustaprosessilla (Playwright, GitHub Actions joka 4. tunti) ja tallennetaan tähän repoon data/jalkapallo.json-tiedostoksi, koska Palloliiton rajapinta estää suorat selainkutsut. Muiden lajien ottelut haetaan suoraan selaimestasi kunkin lajiliiton omasta rajapinnasta juuri nyt kun tämä sivu latautuu. Osa niistä saattaa estää suoran selainkutsun toiselta sivustolta (CORS) — jos näin käy, se näkyy alla olevassa "Datalähteiden tila" -paneelissa, eikä sivu kaadu. Kartalla näkyvät vain ottelut, joiden ottelupaikalle rajapinta antaa koordinaatit. Etäisyys sijaintisi ja ottelupaikan välillä lasketaan suoraan linjaa pitkin (ei teitä pitkin), joten se on suuntaa-antava. Selain saattaa kysyä lupaa käyttää sijaintiasi — sitä käytetään vain paikallisesti etäisyyksien laskemiseen, eikä sitä lähetetä minnekään.
