Ladataan datalähteitä…

Ensimmäinen live-versio. Jalkapallon ottelut haetaan taustaprosessilla (Playwright, GitHub Actions joka 4. tunti) ja tallennetaan tähän repoon data/jalkapallo.json-tiedostoksi, koska Palloliiton rajapinta estää suorat selainkutsut. Muiden lajien ottelut haetaan suoraan selaimestasi kunkin lajiliiton omasta rajapinnasta juuri nyt kun tämä sivu latautuu. Osa niistä (erityisesti Salibandyliitto, Koripalloliitto, Lentopalloliitto, Käsipalloliitto) saattaa estää suoran selainkutsun toiselta sivustolta (CORS) — jos näin käy, se näkyy yllä olevassa "Datalähteiden tila" -paneelissa, eikä sivu kaadu. Liiga.fi sallii ulkopuoliset kutsut suoraan, joten se toimii varmimmin. Salibandyn F-liiga, jääpallo ja amerikkalainen jalkapallo eivät vielä tarjoa rajapintaa lainkaan (edellyttävät myöhemmin sivun sisällön hakua toisella tavalla) ja näkyvät alla placeholdereina. Maajoukkueottelut eivät vielä ole mukana.
